# Prompts for subject research

The orchestrator runs these as fresh general-purpose sub-agents, one per gap listed by `tools/subject_gaps.py`, before the painter draws (see "Subjects before drawing" in `docs/orchestration.md`). Layer 1 first, since layer 2 is written as a departure from it. Several gaps can run in parallel when each writes its own files.

## Layer 1 (the subject as it really is)

> You are researching layer 1 of Teodor's subject library (an AI painter project in {REPO}). Read {REPO}/docs/subjects/README.md for the two-layer structure and the file template, and look at one existing layer-1 page in {REPO}/docs/subjects/ as a model. Write layer 1 for **{SUBJECT}** ({NOTE}). Follow the template exactly. That means: structure with numbers where the literature gives them; viewpoints; light; variation; how painters observe and construct it; common mistakes (what reads stiff, cartoonish or fake); checks for Teodor; and sources with links. Use WebSearch and WebFetch: drawing and painting manuals, natural-history, anatomy or optics references, and museum education pages. Mark values without a source as judgement calls. Painters may be named only as examples of observation, never as rules. Write {REPO}/docs/subjects/{SUBJECT}.md, and the short machine-readable form (key proportions and checks) to {REPO}/studio/subjects.parts/{SUBJECT}.json as {"subjects": {"{SUBJECT}": {...}}}. If the subject belongs inside an existing page (seabirds inside animals), extend that page in a new section instead and say so. Don't edit other files. Report a short summary and the files you wrote.

## Layer 2 (the subject in a style)

> You are researching layer 2 of Teodor's subject library (an AI painter project in {REPO}). Read {REPO}/docs/subjects/README.md, the layer-1 page {REPO}/docs/subjects/{SUBJECT}.md, the style's research {REPO}/docs/styles/{STYLE}.md and its entry in {REPO}/studio/styles.json. Then research how **{STYLE}** renders **{SUBJECT}** ({NOTE}): how the current departs from the layer-1 baseline. Which proportions it stretches or flattens, what it simplifies, idealises or leaves out, its conventions, its typical colour, edge and mark treatment for this subject, and what stays true to life. Look at public-domain works of the current (the Met open-access API and images.metmuseum.org, the Cleveland Museum of Art open-access API), and at scholarship and museum texts. Cite sources with links, and mark judgement calls. Describe the current, never one artist's personal manner: name several works across several artists, and keep only what they share. Write {REPO}/docs/styles/subjects/{STYLE}--{SUBJECT}.md (one file per style and subject, so several researchers can work at once; the style doc links to the folder). Write a short rule list to {REPO}/studio/subjects.parts/{STYLE}--{SUBJECT}.json as {"styles": {"{STYLE}": {"{SUBJECT}": {"rules": [...], "keep": [...], "avoid": [...], "sources": [...]}}}}. Don't edit other files. Report a short summary and the files you wrote.
